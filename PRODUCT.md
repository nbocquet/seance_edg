# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Product Purpose
Calculateur simple du coût salarial des réunions pour l’État de Genève, inspiré du calculateur LVLUP fourni par l’utilisateur.
## Users
Utilisateurs souhaitant estimer le coût d’une réunion et le suivre en direct.
## Capabilities and Constraints
Classes de traitement du PDF local 2024. Annuité 10 par défaut, modifiable. Montants en CHF. Aucun nom personnel nécessaire. Hypothèses explicites et modifiables. Outil indépendant, aucune affiliation officielle affirmée.
## Stack
Choix technique proposé pour cette session : HTML/CSS/JavaScript statiques, sans dépendances. Hébergement à déterminer.
## Evidence on Hand
Echelle Traitement 2024.pdf, fourni dans le répertoire. Référence : https://www.lvlup.fr/tools/calculateur-cout-reunion

## Confirmed Implementation Constraints
HTML, CSS et JavaScript natifs, sans CDN, ouverture directe sans serveur web. Hébergement futur sur GitHub Pages. Exemple initial confirmé : 6 personnes, classe minimale 21, niveau 10, une heure. Usage simple confirmé.
